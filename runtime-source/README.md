# Runtime source

This directory contains the project runtime C#, shaders and required third-party notices. Source paths preserve the private authoring project layout; no game textures, meshes, audio, fonts, prefabs, scenes, Resources data, editor exports or original decompiled scripts are included.

This is not a standalone Unity project. Players use the launcher and import their own original game package. The producer requires the private complete authoring project and a locked Unity editor to create reference data. Do not publish those reference bundles or the authoring Assets.

Project reimplementation source is included under the project owner's authorization. Unity/TMP-derived shaders and the NVJOB water shader retain their upstream notices in ThirdPartyNotices. Static matching and payload scans do not prove independent authorship or constitute legal clearance.
